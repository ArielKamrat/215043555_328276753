# שלב ד' - תכנות מסד נתונים (PL/pgSQL)

שלב זה עוסק במימוש הלוגיקה העסקית והגדרת טריגרים לשמירה על שלמות הנתונים (Data Integrity).

---

## 📂 תכולת התיקייה

* **`AlterTable.sql`** - סקריפט הוספת עמודות תומכות (סטטוס וניקוד).

### ⚙️ פונקציות (Functions)
1. **`fn_calculate_tournament_activity.sql`** - מחשבת את אחוז ההשתתפות הפעילה בטורניר.
2. **`fn_get_top_players_refcursor.sql`** - מחזירה מצביע (Ref Cursor) ל-5 השחקנים החזקים במועדון.

### 🛠️ פרוצדורות (Procedures)
1. **`pr_close_tournament_and_score.sql`** - סוגרת טורניר פעיל, משקללת תוצאות ומעדכנת ניקוד מצטבר למשתתפים.
2. **`pr_promote_club_top_player.sql`** - מאתרת את השחקן המוביל במועדון ומקדמת אותו לניהול (`admin`).

### 🔒 טריגרים (Triggers)
1. **`trg_prevent_invalid_rating.sql`** (`BEFORE UPDATE`) - מגביל נפילת דירוג למקסימום 200 נקודות ומונע דירוג שלילי.
2. **`trg_validate_registration.sql`** (`BEFORE INSERT/UPDATE`) - חוסם הרשמה לטורניר שכבר התחיל.

### 🚀 תוכניות ראשיות (Main Programs)
1. **`main_tournament_processing.sql`** - מריצה את פונקציה 1 (חישוב) ומיד אחריה את פרוצדורה 1 (סגירה וניקוד).
2. **`main_club_report.sql`** - מריצה את פונקציה 2, מדפיסה נתונים מהסמן, וקוראת לפרוצדורה 2 (קידום לאדמין).

### 📝 דוח וגיבוי
* **`Report_Content.md`** - קובץ הדו"ח המלא כולל קטעי הקוד וצילומי המסך להוכחת הרצה.
* **`backup4.sql`** - קובץ הגיבוי המעודכן לאחר הרצת כל פקודות שלב זה.
